Construindo uma Lista de Tarefas com Vue.js

Desenvolvimento de uma aplicação interativa

Introdução

Agora vou apresentar a construção de uma lista de tarefas utilizando o Vue.js.

O objetivo desse projeto é desenvolver uma aplicação simples e interativa, na qual o usuário consiga organizar suas atividades. Para isso, dividimos o funcionamento em quatro etapas: adicionar uma tarefa, marcar como concluída, remover uma tarefa e mostrar um contador de tarefas pendentes.

01. Adicionar uma tarefa

Primeiramente, temos a função de adicionar tarefas.

No código, utilizamos o ref, que é um recurso do Vue.js responsável por armazenar informações reativas, ou seja, informações que podem mudar durante a utilização da aplicação.

Nesse caso, temos uma variável chamada novaTarefa, que armazena o texto digitado pelo usuário, e outra chamada tarefas, que guarda todas as tarefas adicionadas.

Quando o usuário digita uma atividade no campo de texto e clica no botão adicionar, a função adicionar() é executada.

Essa função verifica primeiro se o campo não está vazio. Se houver algum conteúdo, ela adiciona a nova tarefa à lista e limpa o campo de texto para permitir que o usuário digite outra atividade.

02. Marcar como concluída

A segunda funcionalidade é marcar uma tarefa como concluída.

Para isso, cada tarefa possui uma propriedade chamada feita, que inicialmente recebe o valor false, indicando que ainda não foi concluída.

Quando o usuário marca a caixa de seleção, esse valor passa para true.

Isso acontece por meio do v-model, que conecta o checkbox diretamente à informação armazenada no Vue.js.

Dessa forma, conseguimos identificar quais atividades já foram realizadas e quais ainda precisam ser feitas.

03. Remover uma tarefa

A terceira funcionalidade permite remover uma tarefa da lista.

Para isso, utilizamos o evento @click, que executa uma ação quando o usuário clica em um botão.

Nesse caso, utilizamos o método splice(), que remove um elemento da lista a partir de sua posição.

Assim, o usuário consegue excluir qualquer tarefa que não queira mais manter na aplicação.

04. Mostrar o contador de pendentes

Por último, temos o contador de tarefas pendentes.

Para desenvolver essa funcionalidade, utilizamos o computed, que permite calcular automaticamente um valor com base em outras informações.

No nosso código, ele verifica a lista de tarefas, identifica quais ainda não foram concluídas e conta quantas estão pendentes.

Sempre que uma tarefa é adicionada, concluída ou removida, esse número é atualizado automaticamente.

Conclusão

Com isso, conseguimos construir uma lista de tarefas com quatro funcionalidades principais, utilizando recursos importantes do Vue.js, como ref, computed, v-model, v-for e eventos de clique.

Esse exemplo demonstra como o Vue.js facilita a criação de aplicações dinâmicas, organizadas e interativas, sem precisar atualizar manualmente cada informação na tela.
